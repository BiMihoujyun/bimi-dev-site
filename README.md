# bimi-dev-site

`bimi.dev` の**配信用**リポジトリ。GitHub Pages がこの `main` をそのまま配る。

## ここに何を置くか

**生成物だけ。** 記事の原稿も、取り込み器も、集計のコードもここには置かない。
それらは非公開の [`bimi-dev`](https://github.com/BiMihoujyun/bimi-dev) にある。
向こうで書いて、生成された静的ファイルだけがこちらに来る。

**ここは公開リポジトリ。** 置いたものは誰でも読める。手元のパス、CFN、transcript 由来の
生データは、間違っても入れない。

## 仕組み

- `CNAME` の一行（`bimi.dev`）で宛先が決まる。**消すとドメインの設定が外れる**
- `.nojekyll` は Jekyll の処理を止めるために置いてある。消さない
- 証明書（https）は GitHub が自動で取る。`.dev` は https 必須なので外せない

裸の `bimi.dev` を GitHub Pages に向けるために、以下の8本を書く。

## この先

集計ダッシュボードのように**サーバーが要るもの**は、ここには載らない（Pages は静的しか配れない）。
そちらは **AWS** に置く。記事は静的のまま、ここに残す。
